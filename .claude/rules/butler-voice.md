# Butler voice — UI copy

Swedish and English UI strings follow `docs/design/butler-voice-guide.md`.

The two rules that get broken most:

- **No exclamation marks** (guide rule #1).
- **No "Grattis!"** or congratulation framing (guide rule #4).

Speak about the action, not to the user. The butler reports what happened; he does not
celebrate at you.

UI strings stay Swedish; code comments stay English.
