# IDE Configuration Files

This directory contains IDE-specific configuration files for the Butlery project.

## Contents

- **`butlery.iml`** - IntelliJ IDEA/Android Studio project file
  - Module configuration
  - Dependencies and classpath
  - Build settings

## IDE Support

### Primary IDEs
- **Android Studio** - Recommended for Flutter development
- **IntelliJ IDEA** - Full support with Flutter plugin
- **VS Code** - Lightweight option with Flutter extensions

### Configuration Notes
- The `.iml` file is auto-generated by IntelliJ/Android Studio
- Can be safely regenerated if needed
- Contains project structure and dependency information

### Setup Instructions

#### Android Studio
1. Open project root directory
2. IDE will automatically recognize Flutter project
3. Install Flutter plugin if prompted
4. Configure Flutter SDK path in settings

#### VS Code
1. Install Flutter extension
2. Open project root directory  
3. Use Ctrl+Shift+P → "Flutter: New Project" if needed

### WSL Development (Important)
When developing in WSL, always use Windows Flutter via cmd.exe:
```bash
cmd.exe /c "flutter run"
cmd.exe /c "flutter analyze"
```

See [CLAUDE.md](../CLAUDE.md) for detailed WSL setup instructions.
