# CRF Ingredient Parser — Training Pipeline

End-to-end pipeline for training CRF weights for on-device ingredient parsing.

## Steps

1. **Export lexicons** — dump Dart constants to JSON so Python uses identical lexicons:
   ```bash
   dart run scripts/crf/export_lexicons.dart
   ```
   Re-run whenever `KnownIngredients`, `UnitDefinitions`, or `PreparationWords` change.

2. **Collect URLs** — gather recipe URLs from Swedish recipe sites (ica.se, koket.se, arla.se)

3. **Scrape ingredients** — extract raw ingredient lines from JSON-LD markup:
   ```bash
   dart run scripts/crf/scrape_ingredients.dart < urls.txt > raw.txt
   ```

4. **Auto-annotate** — label tokens using the existing IngredientParser:
   ```bash
   dart run scripts/crf/auto_annotate.dart < raw.txt > training.conll
   ```

5. **Manual review** — correct ~500 lines for gold-standard validation. Focus on novel patterns the regex parser misses (ranges, compound names, prep phrases).

6. **Retrain with user corrections** (optional) — single command exports corrections from Firestore, converts to CoNLL (with format validation), merges, and retrains:
   ```bash
   ./scripts/crf/retrain_with_corrections.sh
   ```
   Prerequisites: `firebase login`, `npm install` in functions/, `pip install python-crfsuite scikit-learn`.
   Only needed when sufficient user corrections have accumulated.

7. **Train from scratch** (without corrections) — train the CRF model on base training data only:
   ```bash
   python scripts/crf/train_crf.py --input scripts/crf/data/training.conll --output assets/data/crf_ingredient_weights.json
   ```

8. **Test** — verify the Dart-side CRF tier:
   ```bash
   flutter test test/unit/services/parsing/crf/
   flutter test test/unit/services/parsing/
   ```

See `/docs/crf-training-plan.md` for the full testing checklist.

## CoNLL Format

Tab-separated `token\tlabel`, blank lines between sequences:

```
2       B-QTY
dl      B-UNIT
mjölk   B-NAME

ca      O
1-2     B-QTY
msk     B-UNIT
finriven        B-PREP
pepparrot       B-NAME
```

## Labels

`B-QTY`, `I-QTY`, `B-UNIT`, `B-NAME`, `I-NAME`, `B-PREP`, `I-PREP`, `B-SIZE`, `O`

## Lexicon Parity

`train_crf.py` loads lexicons from `data/lexicons.json` (generated by `export_lexicons.dart`). This ensures the Python feature extractor uses the exact same word lists as the Dart `CrfFeatureExtractor`. Never hardcode lexicons in Python — always re-export from Dart.
