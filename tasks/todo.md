### Design choices

- **What to persist**: `url` only.
  - `extractedText` is derived from a fetch call — regenerated cheaply on next fetch.
  - `parsedRecipe` is derived from text — regenerated by next parse.
  - YAGNI: persist the source-of-truth (URL); rest reconstructs.
- **Key**: single global `url_import_draft_v1` — same shape as text-import. URL-import is one-at-a-time per session.
- **Clear-on-success**:
  - When user navigates from URL-import to text-import edit (`_navigateToTextImport`): URL has served its purpose; clear.
  - NOT on fetch alone — user may still want to retry/edit after seeing extracted text.
- **Don't load if controller already has text**: defensive (controller is initialized empty so this is just-in-case).
